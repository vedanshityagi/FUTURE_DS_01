# Business Sales Performance Analysis

## Project Overview

This project focuses on analyzing business sales data using the Superstore dataset. The objective is to identify sales trends, profitable categories, regional performance, and key business insights through data visualization and dashboard creation.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Dashboard Design

## Dataset

The dataset contains retail sales information, including:

* Order ID
* Order Date
* Product Category
* Sub-Category
* Sales
* Profit
* Customer Segment
* Region

## Key Performance Indicators (KPIs)

* Total Sales
* Total Profit
* Total Orders
* Average Order Value

## Dashboard Visualizations

* Sales by Category
* Profit by Category
* Sales by Region
* Monthly Sales Trend
* Top Performing Products

## Key Insights

* Certain product categories generated higher sales and profit than others.
* Sales performance varied across different regions.
* Monthly sales trends revealed fluctuations in customer demand.
* A small number of products contributed significantly to overall revenue.

## Recommendations

* Focus marketing efforts on high-performing product categories.
* Improve sales strategies in underperforming regions.
* Monitor seasonal trends for better inventory planning.
* Promote high-profit products to maximize revenue.

This project demonstrates the use of Excel for business analytics and dashboard development. The analysis provides valuable insights into sales performance and supports data-driven business decision-making.
